    How it works

    1. Allow a site. The browser asks for access to that address only.
    2. Open a page with a mermaid fence. Wiki, pull request and work item pages all render.
    3. Toggle the source. Each diagram has a Show source button that reveals the original text.

    Diagrams are drawn on your machine. The extension does not send page content anywhere.
